# 全国 20 年租地 · 生机农业选址榜

> 面向「至少 20 年以上租期」的生机农业落地选址。综合评分公式为自研模型，候选地定位到省—市—县（州）级，具体村需实地核实。

---

## 一、综合评分公式（自研）

```
S = 0.12·N + 0.24·O + 0.14·W + 0.12·H + 0.10·C + 0.12·R + 0.11·L + 0.05·T
```

| 符号 | 维度 | 权重 | 说明 |
|------|------|------|------|
| N | 负离子浓度指数 | 0.12 | 森林覆盖、瀑布溪流密集度，生机农业生态基础 |
| **O** | **土壤有机质指数（含肥沃度）** | **0.24** | 有机质 g/kg + 成土母质/团粒结构，越高越「活」 |
| **W** | **水源洁净度指数** | **0.14** | 水源是否干净无污染（远离工业/矿污染） |
| **H** | **重金属洁净度指数** | **0.12** | 当地土壤/水体重金属（Hg/Pb/Cd/As）是否超标，越高越洁净 |
| C | 气候环境适宜度 | 0.10 | 温度、降水、无霜期、作物多样性 |
| R | 租金便宜度 | 0.12 | 租金越低得分越高 |
| L | 20 年+租期可获得性 | 0.11 | 撂荒地/林地/四荒地多、流转政策宽松 |
| T | 交通·水源便利度 | 0.05 | 道路、灌溉取水、机械化条件 |

**权重逻辑**：土壤维度（O = 0.24，已合并原 F 肥沃度）+ 水维度（N+W = 0.26）+ **重金属洁净度 H = 0.12**，三者合计 0.62，对应「生机农业 = 活的土壤 + 干净的水 + 无重金属风险」；租期 0.11 回应「20 年+」核心需求。

**H 重金属洁净度说明**：按「省基准分 + 市县采矿/工业热点降权」启发式赋值（无随机抖动、可复现）。已知重金属超标/采矿热点（如**铜仁万山汞矿**、个旧锡矿、河池/兰坪铅锌、攀枝花钒钛、赣州稀土等）会被显著降权。**凡落位在采矿/工业区的候选，须实地取土样/水样测 Hg·Pb·Cd·As 后才能签约**。

**政策前提**：耕地二轮承包延包后承包期可至 2057 年，流转可签 20–30 年；**林地承包 30–70 年、四荒地（荒山/荒沟/荒丘/荒滩）最长 50 年**——做 20 年+ 优先选林地、四荒地，或签耕地长期流转。

## 五、落地建议

1. **第一梯队首选**：伊春 / 塔河 / 阿尔山 / 黑河 —— 东北黑土天花板，做**主粮 + 中药材**规模化基地（≥ 1000 亩级），但必须配套温室大棚或选耐寒品种。
2. **第二梯队主战场**：云贵川双标记候选做**多作物 / 茶园 / 果园 / 中草药**（100–500 亩级），重点：贵州（黎平、从江、剑河、荔波）、四川（凉山、阿坝、甘孜、雅安）、云南（普洱、临沧、大理、保山）。
3. **第三梯队差异化**：海南（五指山、保亭、琼中）做**热带**；武夷山 / 婺源 / 景宁做**茶叶 + 文旅**；新疆东（哈密、吐鲁番）做**干旱区**试点；**采矿/工业区候选一律先测重金属再谈**。
4. **实地核实 5 件事**：① 村委会确权与流转年限；② 取土样测有机质/**重金属（Hg/Pb/Cd/As）**；③ 取水样测污染；④ 负离子仪实测；⑤ 查当地采矿权/尾矿库分布。
5. **签合同要点**：明确 20 年+ 流转年限、租金递增条款（每 5 年上调不超过 15%）、土地用途（农林）、到期续租优先权、退出机制。

> **本版 v3.0 更新**：新增**重金属洁净度 H 因子（权重 0.12）**，公式由七维升级为**八维**（权重总和仍 = 1.00）。原「F 土壤肥沃度」并入「O 土壤有机质」统一为 0.24。181 个候选全部按新公式重算、重排：**铜仁万山汞矿落位的江口县（梵净山）等被显著降权**（H=45），东北黑土带因远离采矿/工业区而整体前移。T1 由 23 个调整为 28 个、T2 89 个、T3 64 个。

> ⚠️ 本榜为**模型初筛**（自研 8 维公式 + 区域模板 + 重金属启发式降权），具体到村的土地质量、重金属、租金、流转年限须实地核实，评分为主观初判，不可直接作为签约依据。
