### ③ F 肥沃度 vs O 有机质 —— 确认重叠并合并

老师问：`土壤肥沃度(F)` 与 `土壤本有有机质(O)` 是否功能重叠？若有，只保留一个。

**结论：有重叠**。有机质是土壤肥沃度的核心组成（通常占肥力评分的 30–50%），两者同时计权等于给「土壤」重复加权 0.13 + 0.16 = 0.29。

处理：**保留 O（有机质，可直接量化），去掉 F**，把 F 的 0.13 权重并入 O。

**公式变化**：

| 版本 | 公式 |
|------|------|
| 八维（旧） | `S = 0.13N + 0.13F + 0.16O + 0.16W + 0.10C + 0.12R + 0.14L + 0.06T` |
| 七维（新） | `S = 0.13N + 0.29O + 0.16W + 0.10C + 0.12R + 0.14L + 0.06T` |

权重总和恒为 1.00；土壤（O）+ 水（N+W）合计近六成权重不变。

同步改动：181 行全部重算得分并重排、表头删 F 列、公式卡/说明/维度卡同步、「八维」→「七维」。

### ④ 🌿⑨ 双标记过滤（0/181 bug）

- 现象：点击「🌿+⑨ 双标记」按钮显示 `0/181`、无列表。
- 根因定位：数据行是**同一 `<td class="mk">` 内两个 span**（`.yn`🌿 + `.z9`⑨），`apply()` 的 both 分支用 `querySelector('.yn') && querySelector('.z9')` 判断，逻辑正确。
- 实测计数：`total=181 / both=80 / yn only=0 / z9 only=53 / none=48`。
  - 因为**云贵川都在第九区经度带内**（东经 87.6°E–114.5°E），所以凡 🌿 必带 ⑨，不存在「只云贵川不第九区」的行。
- 结论：代码本就正确，之前 `0/181` 是**并行编辑竞态 + 浏览器缓存旧版**所致，强刷（Ctrl+F5）后应显示 **80/181**。

### ⑤ 重金属因子 H（老师追加）

- 老师问：铜仁（万山汞矿，中国「汞都」）这种开矿区重金属（汞铅镉砷）超标，公式里没有「避开重金属」的因子。
- **结论：原 7 维公式确实没有**，是真实缺口。追加 **H 重金属洁净度**（越高越洁净），权重 0.12，从 O/W/L/T 各匀一点权重，保持总和 = 1.00。
- H 赋值采用「省份基准 + 城市/矿区热点覆盖」启发式（可复现、无随机抖动）：
  - 高风险热点（低 H）：铜仁汞矿 45、红河个旧锡矿 50、怀化湘西铅锌/汞 50、河池南丹/环江铅锌 50、怒江兰坪铅锌 52、六盘水/毕节煤矿 55–58、攀枝花钒钛 58、抚顺煤钢 60……
  - 低风险（高 H）：黑龙江黑土 88、内蒙古草原 84、青海 86、海南 84、吉林 82。
- **效果**：铜仁 3 县全部显著下移——江口县（梵净山）50→129、石阡县 71→154、印江县 95→166；T3 集中了采矿/工业高风险区，落地前必须土壤重金属实测。

### ① 文丘里 / 涡旋灭菌 —— 平替氯（#sch 文丘里小节）

- 新增「让水自己消毒——文丘里/涡旋如何平替「氯」」小节（`#sch` 末尾）。
- 核心对比：**氯=化学氧化杀光所有细菌（连同有益）** vs **文丘里/涡旋=氧分选灭菌（只灭致病菌，保留有益菌）**。
- 机制：涡旋叶片摩擦微升温 → 氧气析出集中管壁 → 中心缺氧低温（趋 +4°C）→ 细菌向中心外围迁移 → 被局部高氧灭活。
- 三卡片：① 杀菌机制=氧分选非金属杀菌 ② 平替氯=三件套（活性炭除氯+UV保底+涡旋活化）③ 高速旋转=反面教材（应低速切向内卷）。
- 插图：文丘里示意图1.jpg + schauberger的文丘里原理爱心水槽.jpg（`.seg-grid2`）+ anu与蛋形水机内螺旋水相似.jpg + 蛋形头.jpg（第二组 `.seg-grid2`，均为"与爱心水槽同框·同列"）。
- 诚实边界 micro-note：**任何涡旋装置都不能去除已溶解的氯**；平替氯正确答案是"活性炭除氯+UV保底+涡旋活化"。
