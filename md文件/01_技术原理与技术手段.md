# 技术原理与技术手段

> 来源：泰山量子应用研究院《生机农业技术简介》第二、三、四章

## 一、技术原理

### 核心目标

恢复**「活」的土壤**——补充微生物并激活微生物的活性。

### 土壤为什么是「活」的

- 健康的土壤能自然转化合成有机质、腐殖质、氮肥、磷肥、钾肥等植物所需养分
- 这种天然活性的来源是土壤中大量的**有益微生物**

### 恶性循环的形成

```
化肥农药过量使用
   → 破坏微生物生存环境
   → 有益微生物减少、菌群失衡
   → 土壤肥力转化无法自然完成
   → 只能依赖人工施肥补充
   → 增加成本 + 污染土壤/环境/作物
   → 污染物进一步破坏微生物平衡（恶性循环）
```

### 破解之道

改善微生物的生存环境，并适当为土壤补充有益微生物。

## 二、技术手段

以「微生物有机肥 + 矿物添加」的形态呈现。

### （一）中华曲

农业生产中用微生物自古有之，古代称之为「**曲**」。曲不仅能酿酒、酿醋、发酵面食，还能用于农田养护。

「中华曲」是一种**可食用的传统本土菌种**，早已成为中华先民的基因记忆，更利于华夏子民吸收利用。

#### 1、以牛羊粪为主的微生物基肥

以「中华曲」为主要微生物发酵羊粪、牛粪等肥料，给土地补充肥力的同时补充「益生菌」。

#### 2、美味宝、脱残宝（以中华曲为基础提炼）

| 产品 | 作用 |
|------|------|
| 美味宝 | 快速改良作物口感，有效抑制病虫害滋生 |
| 脱残宝 | 加快降解土壤中残留的有害物质（建议初次使用微生物有机肥的土地使用；确定已停用农药后，第二年可停用） |

### （二）矿物添加

加入「**木鱼石**」和「**沸石**」两种天然矿物，直接补充微量元素，并为微生物提供更适宜的生存环境。

#### 1、木鱼石

- 非常稀有的天然矿物，具珍贵药用价值，古人称「长寿石」，可提升人体免疫力
- 记载于《神农本草经》《本草纲目》等典籍
- 可用于保鲜、净化水质
- 为农作物提供锶、钼、锂、锌、硒等多种微量元素
- 保护和恢复微生物的生存环境

#### 2、沸石

- 具吸附、置换、净化污染物的功能
- 农业常用作土壤改良剂（上世纪 60 年代日本开始大量使用，80 年代前苏联亦开始使用）
- 是一种生化催化剂，促进土壤有益菌生化反应活跃度
- **多孔结构**：1 克沸石内部孔穴表面积可达 300–500 m²，为微生物提供优质藏身场所
- 经「中华曲」培养发酵后，孔隙中贮藏大量微生物，每一粒沸石相当于一个「**益生菌工厂**」
- 温度适宜时微生物大量繁殖、代谢物成为农作物营养；天寒地冻时成为微生物「猫冬」场所

## 三、操作方法

### （一）美味宝、脱残宝的辅助使用

| 项目 | 说明 |
|------|------|
| 稀释比例 | 叶面 1:100；灌根 1:300–500 |
| 用量 | 漫灌 1 kg/亩；滴灌 500 g/亩 |
| 施用周期 | 喷洒两周一次；灌根一月一次 |
| 储存 | 阴凉通风干燥处，温度不低于 15℃ |

**注意事项**：

1. 禁止与杀菌剂同时使用
2. 温度低于 15℃ 时不能使用该方法

### （二）微生物有机肥和矿物添加

#### 1、大田种植

**建议用量**：

| 品类 | 用量 |
|------|------|
| 矿物介质 1 号（超级肥料 1 号） | 1.3 公斤/亩 |
| 矿物介质 2 号（生物动力 2 号） | 1.3 公斤/亩 |
| 矿物介质 3 号（和谐共生 3 号） | 1.3 公斤/亩 |
| 微生物有机肥 | 适量 |

> 矿物介质合计 **3.9 公斤/亩**

**操作方法**：翻耕前，将 1 号、2 号、3 号和适量微生物有机肥均匀撒入土地，再翻耕（深耕、浅耕均可）。

#### 2、果树种植

**建议用量**：1/2/3 号各 1.3 公斤/亩 + 微生物有机肥适量；按每亩棵数平均分配到每棵果树。

**操作方法一（幼龄果树）**：

1. 每棵树分得的矿物介质分成三份（1、2、3 号各一份）
2. 距树干 30–50 cm 处，呈等边三角形刨 3 个坑，深 15–20 cm
3. 将 3 份矿物介质和适量微生物有机肥分别放入 3 个坑
4. 覆土；**不可将矿物介质裸露地面**
5. 建议使用套种器一次性完成挖坑、放置、覆土

**操作方法二（大龄果树）**：

1. 每棵树矿物介质分三等份，每等份再分 1、2、3 号，共 9 份
2. 距树干 30–50 cm 处，呈圆形均匀刨 9 个坑，深 15–20 cm
3. 9 份矿物介质 + 适量微生物有机肥均匀放入 9 个坑，每坑 1 份
4. 覆土；不可裸露地面；建议使用套种器

### （三）注意事项（首年种植）

第一年（尤其春季）因土地尚未恢复健康，可能出现长势弱、病虫害增加、减产，**均属正常现象**，应正确认知、理性应对。

| 现象 | 应对 |
|------|------|
| 春季长势弱、叶片偏小略黄、不油绿 | 完全正常（给养方式不同于化学种植），无需处理 |
| 病虫害增加 | 根源是土壤不健康，土壤恢复后自然减少；若大面积，可用少量低毒/生物/有机/中草药保护液或物理驱虫 |
| 减产 | 第二季起逐年提升，达到甚至超过化学农业水平 |
| 除草 | **禁用除草剂等剧毒农药**；如必须，用微生物除草剂 |
